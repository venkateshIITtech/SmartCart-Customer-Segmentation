# SmartCart-Customer-Segmentation
This project uses K-Means Clustering to group customers based on their purchasing behavior and customer information. The goal is to help businesses understand different customer groups and improve marketing strategies through customer segmentation.

•	Built a customer segmentation model using K-Means Clustering to group customers based on purchasing behavior.

•	Performed data cleaning, feature engineering, feature scaling, and outlier removal using Pandas and Scikit-learn.

•	Visualized customer clusters using PCA to support targeted marketing and business decisions.
